Build a lightweight lead generation engine that processes manually scraped Google Maps data (CSV input), cleans it, enriches it, removes duplicates, and pushes it into a Google Sheet for automated outreach.

IMPORTANT:
- Do NOT use paid APIs
- Do NOT use Google Places API
- System must work with CSV uploads from tools like Instant Data Scraper

---

SYSTEM REQUIREMENTS

1. INPUT (CSV INGESTION)
- Accept CSV file uploads containing Google Maps data
- Expected fields:
  - name
  - address
  - phone
  - website (optional)
- Allow flexible column matching (handle messy CSVs)

---

2. DATA CLEANING
- Normalize:
  - Business names (trim, lowercase for matching)
  - Phone numbers (standard format)
  - Addresses (basic cleanup)
- Remove rows with:
  - Missing business name
  - Duplicate entries

---

3. DEDUPLICATION ENGINE
- Check duplicates using:
  - Business name + phone
  - Business name + address
- Maintain a local database (SQLite or JSON) of existing leads
- Do NOT re-add duplicates across runs

---

4. ENRICHMENT (FREE METHODS ONLY)
- If website exists:
  - Visit site
  - Attempt to extract email using regex
- If no email found:
  - Leave blank (do NOT use paid APIs)
- Extract domain from website
- Tag:
  - has_website = true/false

---

5. LEAD STRUCTURING
Transform into this schema:

- Name
- Email
- Phone
- Company
- Title (blank)
- City (extract from address if possible)
- Source = "Google Maps"
- Status = "new"
- Notes
- Date Added (auto timestamp)
- Last Contact (blank)
- Website

---

6. GOOGLE SHEETS INTEGRATION
- Connect using Google Sheets API (free)
- Append leads to sheet named “Leads”
- Prevent duplicate uploads

---

7. SIMPLE LEAD SCORING
Add a score field:
- +1 if website exists
- +1 if phone exists
- +1 if email found

---

8. FILE STRUCTURE

- main.py (entry point)
- csv_handler.py
- cleaner.py
- deduper.py
- enricher.py
- sheets.py
- database.py
- config.py

---

9. USER FLOW

- User uploads CSV
- System processes:
  clean → dedupe → enrich → format
- Push to Google Sheets
- Print summary:
  - total rows
  - duplicates removed
  - leads added

---

10. ERROR HANDLING
- Skip broken rows
- Log errors to file
- Continue processing (no crashes)

---

11. SETUP INSTRUCTIONS
Include:
- How to upload CSV
- How to connect Google Sheets
- How to run script

---

GOAL

Create a repeatable, no-cost lead processing engine that turns raw scraped data into clean, structured leads ready for automated outreach.

This system should prioritize reliability, simplicity, and speed over complex automation.
